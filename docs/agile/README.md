# Agile execution (Scrum) — TeamUp

Source of truth for how the team works. Mirrors Section 4 of the approved
project proposal; the Jira Scrum board remains the live tracker and this folder
is the in-repo evidence.

| Item               | Practice                                                                                                                                       |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Method             | Scrum with a Jira Scrum board. Small usable increments let the instructor and students give feedback after each sprint.                        |
| Cadence            | Two-week sprints (proposal plans four; PB-09 and PB-10 were planned for Sprints 5-6, see [SPRINT_BACKLOG.md](SPRINT_BACKLOG.md)).              |
| Ceremonies         | Sprint planning at sprint start, 15-minute stand-up on working days, weekly backlog refinement, sprint review and retrospective at sprint end. |
| Roles              | Scrum Master / backlog owner: Aditi Vishal. Quality and test lead: Amogh Dhole and Krishan Lnu. Estimates and documentation: Malaika Farooq.   |
| Definition of Done | [DEFINITION_OF_DONE.md](DEFINITION_OF_DONE.md) — enforced by the PR template and the CI workflow.                                              |
| Backlog            | [SPRINT_BACKLOG.md](SPRINT_BACKLOG.md) — PB-01 to PB-10 with status and repository evidence.                                                   |
| Work-to-code links | Every branch, commit and pull request carries a backlog ID (`PB-04`) — see [CONTRIBUTING.md](../../CONTRIBUTING.md).                           |
