# Project guide

| Location            | Purpose                                                       |
| ------------------- | ------------------------------------------------------------- |
| `src/frontend/`     | UI, feature API clients, hooks, and providers                 |
| `src/backend/api/`  | Server endpoints                                              |
| `src/backend/ai/`   | AI server functions and gateway calls                         |
| `src/routes/`       | TanStack route declarations and screens                       |
| `src/integrations/` | Supabase and authentication connections and middleware        |
| `src/types/`        | Shared domain types                                           |
| `drizzle/`          | PostgreSQL SQL migrations and migration metadata              |
| `supabase/`         | Supabase project configuration                                |
| `public/`           | Public static assets                                          |
| `docs/`             | Architecture and technology documentation                     |
| `tests/`            | Unit tests, opt-in database checks, and manual test scenarios |

Root configuration files configure Vite, TypeScript, ESLint, Prettier, Bun,
Drizzle, and shadcn. Keep these at the root so the tools can find them.

`.workspace/`, `Microsoft/`, and `*.tsbuildinfo` are local tool artifacts, not
application source. They are ignored by Git and can be regenerated by tooling.
